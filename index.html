Project Overview

This project involves the use of Delaunay triangulations to make digital art. On the demo page, upload an image, add points onto the image, and watch digital art be created from the image by overlaying a Delaunay triangulation and filling in the triangles with colors from the image. Learn more about Delaunay triangulations and the underlying algorithm used for this project below.

Delaunay Triangulations

A triangulation is a set of triangles whose vertices are an input set of points. A Delaunay triangulation, developed by Boris Delaunay in 1934, is a specific type of triangulation where the circumcircle of each triangle contains only the vertices of that triangle and no other vertices in the given set of points. Delaunay triangulations have some other special properties as well.For one, they are unique, meaning there is only ever one Delaunay triangulation for a given set of points. Also, the outer edges of a Delaunay triangulation make up the convex hull of the input points. Delaunay triangulations also maximize the internal angles of the triangles, which avoids sharp angles and long, slim triangles. This makes the triangulation look more uniform.

Delaunay triangulations have many applications, including terrain and object surface modeling, point density calculations, and path planning. Delaunay triangulations are also heavily related to Voronoi diagrams (Voronoi diagrams are created using the circumcenter of the triangles in a Delaunay triangulation), which have applications in biology, computer graphics, robotics, chemistry, and more.
