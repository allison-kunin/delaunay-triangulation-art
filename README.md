# Delaunay Triangulation Art
## Project Overview
    This project involves the use of Delaunay triangulations to make digital art. On the demo page, upload an image, add points onto the image, and watch digital art be created from the image by overlaying a Delauanay triangulation and filling in the triangles with colors from the image. Learn more about Delauanay triangulations and the underlying algorithm used for this project below.
